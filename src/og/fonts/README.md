Fonts used only at build time to render Open Graph images (not served to visitors).

- NotoSerifSC-SemiBold-GB2312.woff: Noto Serif SC 600 (via @fontsource/noto-serif-sc 5.3.1), merged and subset to GB2312 hanzi + Latin + common punctuation.
- newsreader-latin-500-normal.woff: Newsreader 500 (via @fontsource/newsreader 5.3.0).
- inter-latin-{500,600}-normal.woff: Inter 500/600 (via @fontsource/inter 5.3.0).
